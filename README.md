# 我的生活台 · 自托管说明

这个文件夹就是一个可以直接部署的静态站点，入口是 `index.html`（单文件，无外部依赖，断网也能用）。

## 方案一：GitHub Pages（推荐，5 分钟）

1. 登录 github.com，右上角 **+ → New repository**，名字填 `lifeapp`，可见性选 **Public**，Create。
2. 在仓库页点 **Add file → Upload files**，把本文件夹里的 `index.html` 和 `.nojekyll` 拖进去，底部 **Commit changes**。
3. 进 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 **main**，目录选 **/ (root)**，Save。
4. 等 1 分钟左右，访问 `https://你的用户名.github.io/lifeapp/`，能看到「我的生活台」就成功了。
5. 手机浏览器打开这个网址 → 菜单里选「添加到主屏幕」。之后从桌面图标进，全屏、离线可用。

## 方案二：Gitee Pages（国内访问更快，需实名）

1. 登录 gitee.com，新建仓库（公开），上传 `index.html`。
2. 进入仓库的 **服务 → Gitee Pages**，按提示完成实名认证后点「启动服务」。
3. 得到网址 `https://你的用户名.gitee.io/仓库名`。
4. 手机浏览器打开 → 添加到主屏幕。

## 必须知道的四件事

1. **地址一旦定下来就别换。** 浏览器按「域名」分配存储，换地址、换仓库名 = 一套全新的空数据。真要换，先在设置里导出备份，再到新地址用「从文本恢复/导入文件」读回来。
2. **仓库是公开的没关系。** 公开的只是页面代码，你的体重、开销、经期这些记录始终只存在你自己手机的浏览器里，不会上传到仓库。
3. **iPhone 必须用 Safari 打开网址再添加主屏幕**，不要用微信内置浏览器打开（微信的存储随时会被清）。
4. **每月备份一次。** 设置页 →「复制备份」，粘到备忘录或发给自己；换手机、清缓存时用「从文本恢复」贴回去。

## 其他平台

任何静态托管都能用：Cloudflare Pages、Vercel、腾讯云静态网站托管、公司内网服务器。
直接上传本文件夹即可，不需要 Node、不需要构建、不需要后端。
